## Original Plan

### User Requirements
- Roles Supported: CONSULTEE and CONSULTANT (not STAFF/ADMIN)
- Role Selection: During onboarding (Step 0)
- Profile Image: Upload to Supabase Storage
- Skip Option: Skippable in dev mode, mandatory in production
- Draft Persistence: Save progress locally for resume capability
- Consultant Availability: Info screen explaining slots must be set on web

### Conflict Handling (Web + Mobile Simultaneous)
- Backend uses upsert pattern - last write wins
- userId @unique on profile tables prevents duplicates
- No errors - data replacement on re-submission

### Flow Structure

**CONSULTEE (5 steps)**
| Step | Name | Fields |
|------|------|--------|
| 0 | Personal Info + Role | name, phone, DOB, gender, timezone, image, role |
| 1 | Profile | occupation, aboutMe, careerStage, company, industry, skills |
| 2 | Preferences | communication method, language, budget |
| 3 | Agreement | ToS, Privacy acceptance |
| 4 | Review & Submit | Summary, submit button |

**CONSULTANT (5 steps)**
| Step | Name | Fields |
|------|------|--------|
| 0 | Personal Info + Role | name, phone, DOB, gender, timezone, image, role |
| 1 | Professional Profile | experience, description, domain, subdomains, headline |
| 2 | Availability Info | Info card (slots set on web) |
| 3 | Agreement | ToS, Privacy acceptance |
| 4 | Review & Submit | Summary, submit button |
